This folder is OPTIONAL.

Knome's own built-in tools (memory, web search, wikipedia, python,
clear-context) live in `core-tools/` and start automatically with
the model -- this folder is not needed for those.

This folder is only useful if you want to add a THIRD-PARTY MCP
server (e.g. GitHub MCP, Slack MCP, etc.) via the browser's
"Settings > Tools > MCP Servers" UI (by giving it a URL). Servers
added there don't need to live in this folder -- it's left empty
purely for documentation/reference, in case you want to keep your
own external server scripts here for organization.
